# 08 — Debug, tracing và testing

Học phương pháp phát hiện, tái hiện và chứng minh đã sửa lỗi: logging có cấu trúc, assertion, GDB/JTAG, core dump, tracing, unit test trên host, mock/fake, integration test và giới hạn của simulator.

## Lộ trình

- Tuần 18: unit/integration test và simulator limits.
- Tuần 19: logging, assertion, core dump và tìm race.
- Xuyên suốt: mỗi bug phải có bước tái hiện, root cause, corrective action và regression test.
